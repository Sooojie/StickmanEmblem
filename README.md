# Summary
[NAME] is a single-player tactical RPG in which players command an army through a fantasy world engulfed in endless war. 
The player assumes the role of a young prince commander who must recruit soldiers, develop their abilities, manage resources, and lead their army through a series of tactical battles. 
The game uses a grid-based combat system in which positioning, terrain, unit classes, weapon effectiveness, and strategic planning determines the outcome of encounters. 
The game features level-based nodes; each node is a story and a battle that players must win.  

## Development Roadmap

1. Grid System, Unit Movement System, Pathfinding
2. Unit, Unit Attributes, Unit Inspection, Unit Movement Specification
3. Turn Management, Player Phase, Enemy Phase, Wait/Skip/Action Remain
4. Enemy AI, AI Behavior/Priority
5. Combat System, Attack Calculation, Weapons, Weapon Triangle
6. Mission System, Deployment, Objectives, Rewards
7. Campaign, Progression, Recruitment, Leveling Up
